Add to this file after quarterly and annual reviews. Reference it when making major decisions or when you feel lost.

## How to Use This File

1. **After each quarterly review:** Add 1-3 key learnings
2. **After each annual review:** Add a summary of the year's major insights
3. **When analyzing past documents:** Add patterns you notice
4. **Before major decisions:** Read through for relevant wisdom

The goal is to accumulate practical self-knowledge — not journaling, but distilled insights.
